AVALIAÇÃO

1. (Múltipla escolha) - 1,0 ponto
Um servidor web recebe uma solicitação feita por um navegador e precisa disponibilizar o recurso solicitado ao cliente. Qual alternativa descreve corretamente esse funcionamento?
2. (Múltipla escolha) - 1,0 ponto
Uma equipe está escolhendo uma tecnologia para hospedar uma aplicação que poderá receber uma grande quantidade de acessos. De acordo com o material estudado, qual servidor é associado a alta performance e escalabilidade, especialmente em servidores com alta carga?
3. (Múltipla escolha) - 1,0 ponto
Durante a configuração de um servidor Linux, um desenvolvedor precisa instalar o Apache. Qual sequência de comandos apresentada no material corresponde à instalação básica?
4. (Verdadeiro ou Falso) - 1,0 ponto
Analise as afirmativas sobre servidores web e marque V para verdadeiro ou F para falso.
( ) Um servidor web responde a solicitações HTTP feitas por navegadores ou outros clientes.
( ) O processo básico envolve uma solicitação (request), o processamento pelo servidor e uma resposta (response).
( ) A resposta de um servidor pode conter dados no formato JSON.
( ) Um servidor web não pode disponibilizar arquivos ao cliente.
5. (Múltipla escolha) - 1,0 ponto
Uma aplicação web será publicada em um servidor e a equipe deseja permitir comunicação por HTTP e HTTPS. Quais portas devem ser consideradas na configuração do firewall, conforme o material?
6. (Múltipla escolha) - 1,0 ponto
Uma empresa deseja proteger os dados transmitidos entre seus clientes e o servidor. Qual recurso de segurança é indicado no material para proteger essa comunicação?
7. (Verdadeiro ou Falso) - 1,0 ponto
Sobre a configuração e segurança de servidores, analise as afirmativas:
( ) O firewall pode ser configurado para permitir as portas 80 e 443.
( ) O Let's Encrypt pode ser utilizado na instalação de certificados de segurança.
( ) O Nginx pode ser configurado para direcionar tráfego para uma aplicação Node.js.
( ) A segurança do servidor é independente da proteção dos dados transmitidos entre cliente e servidor.
8. (Múltipla escolha) - 1,0 ponto
Uma aplicação Node.js está executando localmente na porta 3000. A equipe utiliza Nginx para receber as requisições externas e encaminhá-las para a aplicação. No exemplo estudado, qual diretiva realiza esse encaminhamento?
9. (Dissertativa curta) - 1,0 ponto
Uma equipe precisa colocar no ar uma aplicação web em um servidor Linux.
Explique, de forma resumida, quais seriam os principais passos para configurar um servidor web básico, considerando a escolha do servidor, instalação, configuração de portas e segurança.
10. (Dissertativa curta) - 1,0 ponto
Durante um evento de grande escala, uma aplicação começa a responder lentamente e os usuários relatam dificuldades para acessar o serviço.
Com base no conteúdo estudado, explique quais ações você priorizaria para analisar e resolver o problema de desempenho do servidor. Relacione sua resposta com desempenho, configuração do servidor, tráfego e escalabilidade.
